Mori 的首个正式版本：一个使用 Rust 与 GPUI Kit 编写的原生 AI 聊天客户端，以日常对话、图片、资料和个人助手为中心。

发布日期：2026-10-16。

## 主要功能

- **自定义模型连接**：支持 OpenAI 兼容、Ollama 原生与 Anthropic 协议，自行填写名称、地址与密钥，发现或手动添加模型。
- **模型高级设置**：模型显示名称、Temperature、Top P、可选输出上限与自定义 JSON 参数；按协议及后端适配思考开关。
- **完整聊天体验**：流式回复、思考过程折叠、停止与重新生成、消息复制、编辑创建分支、会话重命名/删除/置顶/搜索及导入导出。
- **富文本与附件**：Markdown、表格、数学公式、代码高亮/复制/下载；图片和文档拖拽、粘贴及图片预览，附件内容哈希去重。
- **个人助手与多模态**：自定义助手提示词；通过支持相应接口的连接生成图片、转写音频、朗读回复。
- **工具扩展**：Function call、MCP 和 Bash，支持逐次确认或信任 Bash 调用；Windows 本地路径说明、桌面工作目录与 UTF-8 中文脚本。
- **界面与性能**：暖白/墨绿浅深主题、简体中文/English、可调整侧栏、Enter/Ctrl+Enter 发送；回复期间可编辑下一条草稿，长对话和长代码采用可视区域渲染。
- **本地数据**：聊天和附件保存在本机，API Key 保存到系统凭据库；升级沿用已有配置和历史记录。

## 下载

- `mori.exe`：Windows x86_64 可执行文件。
- `mori-windows-x86_64.zip`：程序、使用说明、发布指南与项目/第三方许可证。
- `SHA256SUMS.txt`：可执行文件和 ZIP 的 SHA-256 校验值。

首次使用请打开“设置 → 模型连接 → 添加连接”。不内置服务商账户、接口地址或预设模型。

## 支持范围

- 视觉、工具、图片生成、音频和思考开关取决于服务端与模型支持，部分模型无法关闭思考。
- PDF 提取文字，不执行 OCR；音频输入采用录音后转写，目前不提供 Realtime 全双工语音。
- 当前使用 Chat Completions 兼容接口，尚未实现 Responses API、账户云同步或内置向量知识库。
- 会话 JSON 导出不打包二进制附件；完整迁移需同时复制本地数据目录。
